## 표기 기준

- 추천 횟수: 같은 장소를 다룬 서로 다른 Instagram 게시물 수
- 추천 계정 수: `knewnew.official`, `knewnew.style` 중 해당 장소를 추천한 계정 수
- AD: 게시물 캡션의 광고·협찬·제품 제공 고지 또는 Instagram 유료 파트너십 메타데이터 기준
- 카테고리: 캡션·이미지 OCR·카카오맵 업종을 합친 복수 태그
- 좌표: OCR 상호명과 지역 힌트를 카카오맵 공개 검색 결과에 대조해 이름·지역 기준을 통과한 결과만 표시

## 지도와 검색 기능

- 배경 지도: OpenStreetMap 타일을 Leaflet으로 표시
- 장소 정보·좌표: Kakao Map 공개 웹 검색 결과와 대조
- 내 주변: 브라우저 위치 권한을 허용하면 현재 위치를 파란 점과 정확도 원으로 표시하고, 1·3·5·10·20km 반경으로 필터링
- 행정구역: 주소를 기준으로 시·도 → 시·군·구 → 읍·면·동을 단계적으로 필터링
- 네이버·카카오 버튼: 각 지도 서비스의 장소 상세·검색 화면으로 이동하는 링크이며, 현재 전용지도 데이터를 해당 서비스 계정에 자동 저장하는 기능은 아님

미확인 후보는 자동으로 버리지 않고 별도 CSV에 남겨 수동 보정할 수 있게 했습니다.
